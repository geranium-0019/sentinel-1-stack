# 0.1.0-rc1：実データ検証用の配布候補

対象は Linux x86_64（linux/amd64）。Windows は WSL2＋Docker Desktop を使用します。
ISCE2 2.6.5、実行用 Python 3.11.10、NumPy 1.26.4 を含みます。
初期化、SLC・軌道・DEM取得、処理準備、実行・再開、GeoTIFF出力に対応します。

これは正式版ではありません。このタグを使って新しい作業ディレクトリで
取得からアンラップ・出力まで検証してください。元データや既存の処理結果は含みません。
同じ環境構成では Anak の2観測・1ペア（3×1／9×3 looks）の実処理を検証済みですが、
配布候補として最初から取得する通し検証はこれからです。

## ローカルで使う

```bash
scripts/run.sh --image sentinel-1-stack:0.1.0-rc1 init config/project.yaml
scripts/run.sh --image sentinel-1-stack:0.1.0-rc1 download config/project.yaml /path/to/results.geojson
scripts/run.sh --image sentinel-1-stack:0.1.0-rc1 orbit config/project.yaml
scripts/run.sh --image sentinel-1-stack:0.1.0-rc1 dem config/project.yaml
scripts/run.sh --image sentinel-1-stack:0.1.0-rc1 prepare config/project.yaml
scripts/run.sh --image sentinel-1-stack:0.1.0-rc1 run config/project.yaml
scripts/run.sh --image sentinel-1-stack:0.1.0-rc1 export config/project.yaml --include-unwrapped
```

最初に `config/example.yaml` をコピーして `config/project.yaml` を作り、
`work_dir`・対象範囲・処理条件を設定します。SLC取得には利用者自身のEarthdata認証が必要です。
各コマンドの設定は README を参照してください。

## 別PCへファイルで渡す

配布セットの `SHA256SUMS` とファイル群を同じフォルダに置きます。

```bash
sha256sum -c SHA256SUMS
docker load -i sentinel-1-stack-0.1.0-rc1-linux-amd64.tar
tar -xzf sentinel-1-stack-0.1.0-rc1-source.tar.gz
cd sentinel-1-stack-0.1.0-rc1
```

Docker・Bash・Python 3.9以上を用意し、上記のローカル利用手順を実行してください。
イメージだけでなく、同梱ソースの `scripts/run.sh` と設定例も使います。
レジストリへの公開や GitHub での CI 初回確認はまだ行っていません。

## 検証対象の識別

イメージには version とソースcommitをOCIラベルとして付けます。
配布セットの `manifest.json` にイメージID・commit・検証結果を記録します。

```bash
docker image inspect sentinel-1-stack:0.1.0-rc1 \
  --format '{{.Id}} {{json .Config.Labels}}'
```

修正した場合はこのタグを上書きせず、次の候補 rc2 を作ります。
正式版にする際は、合格したイメージに正式タグを追加します。
